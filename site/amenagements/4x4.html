Questions fréquentes

Avant de quitter la route.

Toutes les versions sont-elles à quatre roues motrices ?
Le Transporter 4Motion dispose d'une transmission intégrale. Sur le Transit Custom, la transmission intégrale est disponible sur la version Trail selon les motorisations ; la MS-RT est avant tout une édition sport au look rallye. Nous vous orientons vers la bonne version selon vos terrains réels.
Le 4x4 est-il compatible avec le toit relevable ?
Oui, le toit relevable avec lit intégré peut être installé sur les versions 4x4, notamment sur le Transporter 4Motion. C'est la configuration favorite de nos clients passionnés de sports de plein air.
Quelle consommation et quel entretien ?
Les motorisations diesel EcoBlue et TDI modernes limitent le surcoût de la transmission intégrale. L'entretien se fait dans le réseau constructeur ou dans nos ateliers ; nous vous accompagnons sur les intervalles et la garantie.
